Frame the decision, observation period, comparison groups and missing evidence. Inspect loaded schemas and sample values to establish actual units and keys. Identify duplicate keys, null fields and changes in coverage before calculating trends. Keep alternative explanations separate from measured changes.

When a new report and historical records disagree, compare like-for-like scopes. Join explicit keys, count unmatched rows, and use SQL for sums and differences. Missing category/unit/time information is a reason to seek a supplemental attachment or leave a finding conditional. A model extraction is a versioned observation with supporting quote and location, not automatically verified truth.

For the portable document_observations example, inspect the ingest parameter schema. It accepts small operational CSVs with item/value/category, text PDFs using the package's declared item,value grammar, or images/scanned PDFs with a configured model_alias. Do not assume that every PDF has extractable text. A new prompt or schema can trigger supplemental extraction. Review outputs and evidence before joining them to existing tables.

Deliver a complete analysis containing the comparison basis, measured changes, evidence references, unresolved gaps and what additional information would settle them. The method and output should fit the user's goal. Do not turn the example into a fixed tool sequence or have a program template write the conclusion. Preserve the workspace for follow-up files.
